# Changelog

## [0.1.0] - 2026-11-17

最初の公開版。

- NDMF のビルド時に、対象のテクスチャをグラデーションで塗り替える(元のテクスチャとマテリアルは書き換えない)
- NDMF のプレビューで、ビルドしなくても結果を確認できる
- エディタ(Tools/faketuna/Spoitable Color Changer)
  - レイヤーごとの色(グラデーションのバー)と、塗りマスク・画像マスク・グラデーションマスク
  - 範囲選択の道具(矩形・投げ縄・ペン選択・色選択・UV 島)と、描画の道具(ペン・ブラシ・消しゴム・バケツ)
  - 色の経路(点を結んだ線に沿って色を並べる。Normal / Relative Grade、1 レイヤーに複数)
  - シーンビューでのモデルへの直接操作と、選択範囲の表示
